# OctoConfigurator
Mit dem Konfigurator werden alle Instanzen zu einem OctoPrint-Server angelegt: Status, Druckjob, Temperaturen, Verbindung und System. Der Konfigurator wird normalerweise von der OctoDiscovery angelegt und erhält dabei die UUID des Servers.

## 1. Konfiguration

Feld | Beschreibung
------------ | ----------------
UUID | Kennung des OctoPrint-Servers. Sie wird beim Erstellen in die angelegten Instanzen übernommen und ordnet bereits vorhandene Instanzen dem Server zu.

Die Liste zeigt je Instanztyp, ob eine passende Instanz schon existiert. Über **Erstellen** wird die fehlende Instanz angelegt.
